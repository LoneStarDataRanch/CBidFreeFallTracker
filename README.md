# CigarBid FreeFall Tracker

A bookmarklet and browser snippet for tracking prices on [CigarBid.com](https://cigarbid.com) FreeFall auctions. Runs directly in your browser with no extension or installation required.

Built on the original work of [u/patdavid](https://www.reddit.com/r/cigars/comments/lh5rq4/cigarbid_free_fall_lowest_tracker_simple/) and u/Even-Foundation2433's auto-buy approach.

---

## Features

- **On-page floating panel** showing current price, lowest seen, target price, price history count, and estimated time to target
- **MutationObserver-based** tracking (event-driven, not polling) so it catches price drops the instant the DOM updates
- **Per-tab target price** set directly in the panel. No editing code. Each tab gets its own price independently, perfect for watching multiple auctions at once
- **Arm/Disarm auto-buy toggle** in the panel. Always starts disarmed. The "I Confirm this Purchase" checkbox on the page remains the final failsafe
- **Audio alerts** when price hits your target or comes within 10% of it
- **Price sparkline graph** showing the trend over time, with imported vs. live data visually separated
- **Price drop rate** ($/min) based on the last 10 price changes
- **Estimated time to target** based on current drop rate
- **Full price history** with timestamps logged to console
- **CSV download** saves a real file to your Downloads folder named after the auction (e.g. `cigarbid_Oliva_Serie_V_2026-02-18.csv`)
- **CSV upload** lets you load historical price data from a previous run of the same cigar
- **Session persistence** via localStorage, keyed per auction lot. Refresh the page and your history, lowest seen, and target price all restore automatically. Sessions expire after 4 hours
- **Pause/Resume** button. Pause without losing data, resume where you left off
- **Multi-tab coordination** via BroadcastChannel. Shows other open tracked tabs and which is closest to its target
- **Browser notifications** that fire even when Chrome is minimized
- **Draggable panel** so you can move it out of the way

## Installation

### Option 1: Bookmarklet (Recommended)

The bookmarklet is the fastest way to use this. One click on any FreeFall page activates the tracker.

1. Create a new bookmark in your browser bookmarks bar
2. Set the **name** to whatever you like (e.g. `FF Tracker`)
3. Set the **URL** to the entire contents of the code block below
4. Save the bookmark
5. Navigate to a CigarBid FreeFall auction page and click the bookmark

### Option 2: Chrome DevTools Snippet

Better for development or if you want to tweak the code easily.

1. Open Chrome DevTools with `Ctrl+Shift+I`
2. Click the **Sources** tab
3. In the left panel, find **Snippets** (click `>>` if you don't see it)
4. Click **+ New snippet** and name it `CigarBid FreeFall`
5. Paste the contents of `cigarbid_freefall_v5.js` into the editor
6. Press `Ctrl+S` to save

To run: Navigate to a FreeFall auction page, open DevTools, go to Sources > Snippets, click your snippet, and press `Ctrl+Enter`.

## Usage

1. Navigate to a CigarBid FreeFall auction page
2. Click the bookmarklet (or run the snippet)
3. The tracker panel appears in the top-right corner of the page
4. **Watch** the price for a few minutes to see where it's trending
5. **Type your target price** into the input field in the panel and click Set (or press Enter)
6. If you want to actually buy: **check the "I Confirm this Purchase" checkbox** on the auction page first
7. Click **Arm Auto-Buy** when you're ready. Click again to disarm at any time
8. Walk away. Audio and browser notifications will alert you when the price hits your target

### Panel controls

| Control | Description |
|---|---|
| Target price input | Set your buy target. Each tab is independent |
| Arm Auto-Buy | Toggle auto-buy on/off. Red = armed, orange = disarmed with target set |
| Save CSV | Downloads price history to your Downloads folder |
| Load CSV | Import historical data from a previous auction CSV |
| Clear | Wipes saved session data for this auction |
| Pause / Resume | Pause tracking without losing history |
| Close | Remove the panel and stop tracking. Session is saved |

```js
obsDisconnect()   // same as clicking Close
```

## Anti-debugger note

CigarBid may pause script execution when you open DevTools. If your page freezes when you open the inspector:

1. Open DevTools (`Ctrl+Shift+I`)
2. Click the **Sources** tab
3. Press `Ctrl+F8` to disable "pause on debugger statements"
4. Refresh the page and re-run the tracker

---

## Auto-buy safety

The auto-buy feature clicks the Buy Now button when the price hits your target. However, CigarBid requires you to check **"I Confirm this Purchase"** before a purchase completes. The script does not check that box automatically. You must pre-check it yourself before arming, which keeps a human in the loop and prevents accidental purchases.

---

## Multi-tab workflow

1. Open multiple FreeFall auction tabs
2. Click the bookmarklet on each tab
3. Watch the sparklines for a few minutes to see where each auction is trending
4. Set your target price on each tab individually
5. Pre-check the confirm checkbox on tabs you want to buy from
6. Arm those tabs when you're ready

The multi-tab section at the bottom of each panel shows which tab is currently closest to its target price.

## Notes

- Sessions are stored in `localStorage` and expire after 4 hours
- The drop rate and ETA calculations only use live data points, not imported CSV data
- The bookmarklet and snippet run identical code. The bookmarklet is minified for size
- Syncs across devices if you use Chrome bookmark sync (bookmarklet) or DevTools sync (snippet)
